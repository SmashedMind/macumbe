# MACUMBÊ — Vestimos sua fé

Site estático da loja Macumbê, pronto para publicar gratuitamente no GitHub Pages.

## Como publicar

1. Crie um repositório **público** chamado `macumbe` na sua conta GitHub.
2. Na página do repositório, escolha **Add file → Upload files** e envie o conteúdo desta pasta (`index.html`, `images/`, `.nojekyll` e `README.md`). Não envie apenas o ZIP.
3. Acesse **Settings → Pages**. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Escolha a branch `main`, pasta `/(root)` e clique em **Save**.
5. Aguarde a publicação. O endereço costuma ser `https://SEU-USUARIO.github.io/macumbe/`.

## Antes de divulgar

- Confirme fotos e descrições dos produtos (alguns nomes são provisórios).
- Confira preços, tamanhos, tecidos, disponibilidade, entrega e política de troca.
